1. Project Overview & Business Logic

Edito Kya Hai?

Edito ek modern, ultra-fast, aur 100% Free Browser-Based Audio, Video, aur Image Studio hai. Yeh professional musicians, podcasters, video editors, aur graphic designers ke liye banaya gaya hai. Iska sabse bada feature yeh hai ki yeh 100% Client-Side execute hota hai — yaani user jo bhi gana (MP3/WAV), video (MP4/WebM) ya photo upload karta hai, woh kisi bhi server par upload nahi hoti. Sabhi mathematical DSP operations, neural AI calculations, aur transcoding directly user ke computer/phone ki RAM aur GPU me run hote hain.

💡 The Core Problem Edito Solves:

Aam taur par log audio split karne ke liye Moises.ai use karte hain, background remove karne ke liye Photoroom ya remove.bg, aur video to audio convert karne ke liye CloudConvert use karte hain. In sabhi tools me 3 bohot badi samasyaayein hain:
1. Paid Subscriptions: Free tier me sirf 1-2 minute ki limit hoti hai ya 5 exports ke baad credit card maangte hain.
2. Privacy Risk: User ki personal recordings aur photos unke cloud server par upload hoti hain.
3. Upload/Download Latency: 100MB ka video pehle cloud pe upload hota hai (jisme 2-3 minute lagte hain) aur phir convert hokar download hota hai.

Edito Solution: Edito WebAssembly (WASM), WebAudio API, aur WebGPU ka use karke sab kuch user ke device par bina 1 byte upload kiye instantaneous speed se process karta hai. Unlimited usage, 0 watermarks, aur 100% privacy!

@breezystack/lamejs In-browser MP3 audio compression aur encoding Browsers natively WAV export toh kar sakte hain par MP3 encode nahi kar sakte. LameJS pure JavaScript MP3 encoder hai jo bina server ke genuine compressed MP3 generate karta hai.

fflate Ultra-fast in-browser ZIP archive generation Jab user 'Split Audio' ya 'Bulk Resize' use karta hai, multiple files ko instant in-memory ZIP package me bind karta hai without server load.

  • backend/src/controllers/admin.controller.js: Admin summary KPIs, tool leaderboards, daily trend line, aur error logs compute karta hai.

5. Core 11 Audio Tools — Deep Technical Breakdown

1. AI Stem Separator (/stems)

AI Neural Model

Kaise kaam karta hai: Gane ko 2 ya 4 separate audio tracks me split karta hai (Vocals, Drums, Bass, Other).
Under the hood: Browser me ONNX Runtime Web WebGPU engine ko initialize karta hai. HTDemucs v4 ya Spleeter quantized weights download hokar WebGPU tensor memory me aate hain. Audio ke spectrogram slices infer hokar individual Float32Array stems generate karte hain jise user independently mute, solo, ya volume control kar sakta hai.

2. AI Vocal Remover & Karaoke (/audio/vocal-remover)

Phase Cancellation + Neural

Kaise kaam karta hai: Kisi bhi song se vocals ko mute karke karaoke backing track ya sirf isolated acapella banata hai.
Under the hood: Stereo music me lead vocals hamesha center me mixed hote hain (Left aur Right channel me identical hote hain). Center-channel phase cancellation algorithm (Left[i] - Right[i]) * 0.85 use karke center voice ko cancel karta hai, jabki wide instruments (guitars, synths, stereo reverbs) intact rehte hain.

3. Video to Audio Converter (/audio/video-to-audio)

WebAudio PCM Demuxer

Kaise kaam karta hai: MP4, WebM, ya MOV video se audio track extract karke MP3 ya WAV file banata hai.
Under the hood: decodeAudioFromFile video file ke ArrayBuffer ko Web Audio API decodeAudioData ke through PCM Float32 samples me decode karta hai. Phir @breezystack/lamejs se genuine MP3 bitstream ya 16-bit PCM WAV banakar instant sound ke saath download karwata hai.

4. Waveform Audio Cutter (/audio/cutter)

Sample-Level Slicer

Kaise kaam karta hai: Song ke start aur end points choose karke ringtone ya audio clip banata hai.
Under the hood: sliceAudioBuffer exact sample indices calculate karta hai: startSample = trimStart * sampleRate aur endSample = trimEnd * sampleRate. Naya AudioBuffer allocate karke audio samples copy karta hai aur Optional Fade In/Fade Out linear gain curve apply karta hai.

5. Audio Bitrate Compressor (/audio/compress)

Bitrate Quantizer

Kaise kaam karta hai: Badi audio files ka size 60% se 80% tak reduce karta hai (e.g., 20MB WAV to 2MB MP3).
Under the hood: User ke dwara chune gaye target bitrate (64k, 96k, 128k, 192kbps) par Mp3Encoder ko configure karke Psychoacoustic model se inaudible frequencies ko compress karta hai.

6. Tempo & Pitch Shifter (/audio/speed)

Linear Resampler

Kaise kaam karta hai: Audio ki speed 0.5x se 2.0x tak change karta hai bina pitch distort kiye.
Under the hood: changeBufferSpeed function fractional index interpolation karta hai: destData[i] = srcData[idx0] * (1 - frac) + srcData[idx1] * frac. Isse audio smoothly speed-up ya slow-down ho jati hai.

7. Audio Merger (/audio/merger)

Sequential Concatenator

Kaise kaam karta hai: Multiple songs ya audio clips ko ek ke baad ek jodkar single long track banata hai.
Under the hood: Sabhi uploaded files ke buffers ko decode karke total length calculate karta hai aur ek combined master buffer me copy karke smooth seamless single file export karta hai.

8. Audio Splitter (/audio/split)

Zip Segmenter

Kaise kaam karta hai: Badi recordings ya podcasts ko equal parts ya silence ke aadhar par split karke ZIP file deta hai.
Under the hood: Duration ko split parts me divide karke sub-buffers banata hai aur fflate.zipSync use karke browser memory me bina kisi temporary file ke instant ZIP package generate karta hai.

9. Volume Booster (/audio/volume), 10. Audio Converter, 11. Blank Audio Generator

DSP Gain & Transcoding

Gain scaling mathematical formula: gain = 10^(dB / 20). Sample clipping protection ke saath loudness amplify hoti hai. Blank generator exact milliseconds ka zeroed silent buffer generate karta hai.

6. Core 8 Creative Photo & Video Tools — Deep Technical Breakdown

1. Video Clip Trimmer & Speed Editor (/creative/video-editor)

MediaRecorder + Stream Capture

Kaise kaam karta hai: MP4, WebM, aur MOV video clips ko start aur end points par trim karta hai, speed adjust karta hai, aur audio mute/unmute karta hai.
Under the hood: HTML5 video element se captureStream() call karta hai. Target trimStart par seek karke browser ke native MediaRecorder API ko start karta hai. Video play hota hai aur trimEnd par exact cut hokar recorded chunks ko genuine trimmed MP4/WebM blob me convert karke download karwata hai.

2. Watermark Remover & Inpainter (/creative/remove-watermark)

Multi-Pass Diffusion Inpainting

Kaise kaam karta hai: Photo me se watermark, logo, ya unwanted object par brush ghumane par use gayab kar deta hai.
Under the hood: inpaintCanvasRegion function dual-canvas architecture use karta hai (Original image + Mask canvas). Mask ke pixels ko detect karke unke aas-paas ke 8-neighborhood unmasked clean pixels ka weighted average compute karta hai. 3 sequential diffusion passes me watermark texture seamlessly blend ho jata hai.

3. Background Cutout (/creative/remove-background)

Euclidean RGB Alpha Matting

Kaise kaam karta hai: Photo ka background hata kar transparent PNG cutout banata hai ya solid studio color se replace karta hai.
Under the hood: removeBackgroundCanvas image ke corner pixels se background color sample karta hai. Har pixel ka Euclidean color distance calculate karta hai: sqrt((R - bgR)^2 + (G - bgG)^2 + (B - bgB)^2). Agar distance threshold tolerance se kam ho, toh alpha channel ko 0 (100% transparent) kar deta hai.

4. Bulk Image Resizer (/creative/resize-image)

Bicubic Canvas + Binary Search Compression

Kaise kaam karta hai: Ek saath 20+ images ko Instagram/YouTube presets ya exact pixels par resize karta hai aur target KB size achieve karta hai.
Under the hood: High-quality bicubic interpolation canvas scaling apply karta hai. Agar user ne 'Target Size 100KB' set kiya hai, toh algorithm binary search (6 iterations) karke quality factor (0.05 se 1.0) ko optimize karta hai aur sabhi resized images ko fflate se instant ZIP bana kar download karata hai.

5. Photo Canvas Editor (/creative/photo-editor)

Interactive 2D Canvas

Brightness, Contrast, Saturation CSS filters, 90-degree rotations, horizontal mirroring (ctx.scale(-1, 1)), aur real-time freehand pencil sketching canvas coordinates par execute hoti hain.

6. Photo Collage Maker (/creative/make-collage)

Grid Layout Engine

2x2, 1+2, aur 3x3 responsive grid slots me multiple photos ko render karta hai with custom border radius aur gap spacing.

7. Aesthetic Photo Filters (/creative/apply-effects)

LUT Pixel Shaders

Cyberpunk (magenta/cyan push), Vintage 1980 (warm sepia curve), Radial Vignette shadow mask, aur RGB shift glitch filters directly canvas image data par render hote hain.

8. Face Retouch (/creative/retouch)

Skin Smoothing & Facial Enhancement

Bilateral Gaussian skin smoothing filter, blemish tone blending, eye brightness contrast pop, aur teeth whitening saturation compensation ke saath split-slider before/after preview deta hai.

7. Moises-Style Multitrack Studio Workspace
